## 🚀 How to Deploy on GitHub Pages (Free Hosting)

1. **Create a GitHub Repository**:
   - Go to [GitHub.com](https://github.com) and click **New Repository** (e.g., `kwality-cp-delhi` or `<your-username>.github.io`).
2. **Push These Files**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Kwality Restaurant luxury website"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
3. **Enable GitHub Pages**:
   - Go to your repository **Settings** → **Pages**.
   - Under **Branch**, select `main` and root `/` folder, then click **Save**.
   - Your website will be live in ~60 seconds at `https://<your-username>.github.io/<repo-name>/`.
