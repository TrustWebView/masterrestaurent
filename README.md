# Kwality Restaurant — GitHub Pages Image-Safe Build

This build embeds all website images directly inside `index.html`.
No `images/` folder is required.

Upload these files directly to the repository root:
- index.html
- .nojekyll
- README.md

Then enable GitHub Pages from `main` → `/ (root)`.

No npm, Node.js, Vite, React, or build command is required.
