# Kwality Restaurant — GitHub Pages Rebuilt

This version is rebuilt from scratch to avoid the CSS/JS loading problem.

## Important
Upload the **contents** of this folder to the root of your GitHub repository:

- `index.html`
- `.nojekyll`
- `images/`

Do not upload the outer folder itself.

The page is self-contained: all CSS and JavaScript are inside `index.html`. No npm, Node.js, Vite or build command is required.

## GitHub Pages
Repository → Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.

The reservation form is frontend-only and opens a WhatsApp booking message.
